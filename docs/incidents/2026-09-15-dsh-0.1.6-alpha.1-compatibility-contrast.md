## Confirmed API drift (each pinned by source inspection, not inference)
1. **`@deepseek-ai/dsh-settings`: `settingsNamespace()` helper REMOVED** (packages/settings/settings/src/index.ts has no such export; old RUN + DEV still export it). `register(ns: string & SettingsNamespaceInput<Namespace>, schema, options)` now takes a plain branded string; built-ins do `settings.register('agent-presets', …)` (packages/preset/agent-presets/src/index.ts:192). Breaks `web-compact-config/src/index.ts:18,110` and bridge.spec. Also **`deepEqualJson` is now default-exported, not a named export**.
2. **`@deepseek-ai/dsh-client-runtime` package GONE** (dissolved; `dsh-client-connection`, `dsh-client-test-runtime` exist). Client faces used by web-compact-config + web-file-editor moved: `SettingsScope` → `@deepseek-ai/dsh-client-ui-settings/client` (settings-contract.ts), `SnapshotStore` → `@deepseek-ai/dsh-client-store`, `ClientContext` → cordis `Context`.
3. **TokenMeter now depends on `ctx.sessionProjections` from the NEW `@deepseek-ai/dsh-session-projection` package** — the seams left `dsh-session` on the new tree. All 4 command tests + 10 engine tests die in `new TokenMeter` because the test Context lacks the projection plugin. Fix: inject/provide the projection plugin in test contexts.
4. **`TokenMeasurement.logRevision`: number → `SessionLogOffset`** (packages/llm/token-meter/src/types.ts) — our local `MeterMeasurement` cast no longer satisfies parameters expecting `TokenMeasurement`.
5. **`SummarizationInput.system?: string` REMOVED** — messages now carry the derived system head inline. Breaks archive.spec.ts:27 (and the runtime assumption in archive.ts summarization path).
6. **`RegionDependencies` gained a required `recover(error, agent, sourceEventSeqs, signal?)`** (compaction-basic/src/region.ts) — our engine's `regionDependencies()` return shape no longer assignable.
7. **`Message` role union no longer includes `'tool'`** where archive.ts(45) compares it — `dsh-llm` message typing drifted.
8. **`dsh-session` lost `SessionSeq`/`eventAt` surface used by compaction-basic's region logic under unchecked compile** (region.ts diffs against the old checkout; evidences deeper engine drift).
9. **Compact-config-command tests only:** `CommandInvocation` casting broken (brand/shape drift in commands package).
10. **Container-level (non-plugin-code):** `@deepseek-ai/dsh-client-runtime` junction + `monaco-editor` pin both resolve-able only against the OLD checkouts; `monaco-editor` is ABSENT from the new release node_modules (re-link script marks it optional and skipped). FileEditor plugin bundle build + delivery need a monaco story per target.
